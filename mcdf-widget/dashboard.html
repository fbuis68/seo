Prototype de modèle de données et de moteur de restitutions pour le widget IA MCDF. Les jeux de données ci-dessus sont générés (seed.py) à partir du schéma relationnel schema.sql ; chaque restitution est une fonction Python isolée dans reports.py — la même brique qu'appellerait le copilote conversationnel (function calling) pour répondre à « quel est le taux de nouveaux clients ce mois-ci ? » ou « montre-moi les 30 derniers stagiaires ». Prochaine étape : exposer ces fonctions derrière une API et les brancher sur les données réelles de MCDF.

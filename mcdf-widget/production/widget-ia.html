Widget IA MCDF — module « génération de rapports » (lecture seule). Les données viennent de l'API MCDF en direct (/wa/{entité}/list), pas d'un jeu de démonstration. Le remplissage réel par session n'est pas encore calculable (le lien session↔inscrits n'a pas encore été confirmé côté API — voir modules/03-documents/NOTES.md et ARCHITECTURE.md) : le panneau « Sessions programmées » montre un volume, pas un taux de remplissage réel. Le CA par formateur est estimé (tarif jour × durée), pas facturé réellement.

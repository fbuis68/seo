Assistant Qualiopi -- v1 decouverte

Ce module n'affiche pas encore d'indicateurs Qualiopi habilles : il teste en direct les entites repérées dans le code source et montre ce qu'elles renvoient réellement, pour construire le vrai tableau de bord sur des champs confirmés, pas supposés.

Interrogation des entités candidates...
Ces indicateurs n'ont aucune source connue dans l'API MCDF (probablement saisis ailleurs -- écran de paramétrage, tableur externe -- comme les pages web du client). En attendant de trouver où les lire automatiquement, saisissez-les ici : enregistré uniquement dans ce navigateur (pas de base de données côté serveur pour ce widget), utilisez « Copier en JSON » pour transférer les valeurs vers un autre poste si besoin.
Lecture seule -- mêmes règles que widget-ia.html (cookie de session déjà actif, aucun appel d'écriture). Une fois les bons champs confirmés ici, l'onglet « Détection API » sera remplacé par de vrais indicateurs Qualiopi calculés en direct ; l'onglet « Saisie manuelle » restera pour ceux qui n'ont pas de source dans MCDF.
